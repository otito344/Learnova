**Learnova**

Learnova is a web-based learning management and academic support system designed to provide students with a centralized platform for accessing course materials, receiving academic announcements, managing courses, and getting AI-powered academic assistance.

The project was originally developed as a final-year Software Engineering project and is being further developed as a modern learning platform.

**Features**

Student registration and login
Secure user authentication
Student and administrator dashboards
Course management
Learning material upload and access
Academic announcements
Student profile management
Role-based access for students and administrators
AI-powered academic chat support
Centralized learning resources

**System Architecture**

Learnova follows a three-tier architecture:

1. **Presentation Layer** – React.js and Tailwind CSS
2. **Application Layer** – Node.js and Express.js
3. **Data Layer** – MongoDB Atlas

The frontend communicates with the backend through REST API endpoints, while the backend handles authentication, application logic, database operations, and AI requests.
